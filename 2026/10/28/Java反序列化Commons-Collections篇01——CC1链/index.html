0x01 前言

本篇开始，逐步学习java反序列化的利用链，建议各位师傅在浏览本文的时候自己也去调试debug一下，这样才能真正理解，光看很难真正理解原理，且容易自己混乱（亲身经历（苦笑））。尤其是find usages的部分一定要自己去查找，这对于之后的学习和以后大家自己尝试其他利用链具有很大的学习意义。

0x02 环境搭建

  • JDK8u65
  • openJDK 8u65
  • Maven 这里用的是3.9.3 ，如果自己在使用的时候不行可以尝试降版本

创建完成后，在项目的File->Project Structure中修改Modules

0x03 TransformMap版CC1攻击链分析

反序列化攻击的入口一定是readObject()，尾部则是一个可以进行命令执行的方法，中间链子一步一步传递到尾部。所以我们一般都从尾部往入口找，这样我们的试错次数会极大的减少，因为有些链子在往上查的时候会断掉，如果从入口往下找，工作量简直是天文数字。

0x04 EXP编写

第一版EXP

实际运行可以发现其实我们没法成功调出计算器，这里面有三个需要解决的问题

  • Runtime 对象不可序列化，需要通过反射将其变成可以序列化的形式。

  • setValue() 的传参，是需要传 Runtime 对象的；而在实际情况当中的 setValue() 的传参是这个东西

  • 解决上文提到的，要进入 setValue 的两个 if 判断
