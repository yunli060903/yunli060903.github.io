Java反序列化Commons-Collections篇11——总结篇

0x01 前言

磕磕绊绊也是终于将CC链学完了，不过回头看自己学第一条链子到现在也是颇有感想，一开始一点思路都没有，用find Usages都用不明白，链子也是全是按着师傅们的文章照猫画虎，现在也是可以自己尝试找链子，还是蛮有成就感的。但学了这么多也时不时会弄混，在最后一篇就来好好总结一下，给CC链的学习画上一个完美的句号。

0x02 CC链

CC1

  • 适用版本

    • Commons-Collections 3.1-3.2.1
    • JDK1.8以前或小于JDK1.8 u71

  • 修复方案

    • JDK版本>=8u71
    • 拉黑 sun.reflect.annotation.AnnotationInvocationHandler
    • 不可信输入禁止 ObjectInputStream 反序列化 / 白名单

  • 利用链

    • setValue利用链

    • LazyMap利用链

    • 分析文章

CC2

  • 适用版本

    • Commons-Collections 4.0
    • 测试jdk1.8 8u301、jdk11和jdk15可以正常利用，jdk16利用失败

  • 修复方案

    • Commons-Collections>=3.2.2
    • 拉黑 org.apache.commons.collections.comparators.TransformingComparator

  • 利用链

  • 分析文章

CC3

  • 适用版本

    • Commons-Collections 3.1-3.2.1
    • 由于还是利用到AnnotationInvocationHandler类，所以利用JDK版本同cc1

  • 修复方案

    • 拉黑com.sun.org.apache.xalan.internal.xsltc.trax.TemplatesImpl
    • 白名单

  • 利用链

    • CC1作为前半段

    • CC6作为前半段

    • 分析文章

CC4

  • 适用版本

    • Commons-Collections 4.0
    • 测试jdk1.8 8u301、jdk11和jdk15可以正常利用，jdk16利用失败

  • 修复方案

    • 拉黑 TransformingComparator + TemplatesImpl
    • 白名单

  • 利用链

  • 分析文章

CC5

  • 适用版本

    • Commons-Collections 4.0
    • 测试jdk1.8 8u301、jdk11和jdk15可以正常利用，jdk16利用失败

  • 修复方案

    • 拉黑BadAttributeValueExpException
    • 白名单

  • 利用链

  • 分析文章

  • 适用版本

0x04 小结
