final

对于final修饰的变量有一些不同，我们需要分情况来讨论了

我们分为两种情况：直接赋值与间接赋值，对于直接赋值的变量，我们即使进行反射修改，但改的只是堆中的值，对象中的值并不会被改变，同样序列化和反序列化中的过程中存储的还是原值。但

至于什么情况是直接赋值呢，所谓直接赋值，其实就是编译时赋值，也就是在创建字段时就对字段赋值，并且值为 JAVA 的 8 种基础数据类型或者 String 类型，用个更笼统的说法就是单纯字面量，用new，方法调用，表达式运算这种得出来的值都不算。直接赋值外的其他情况都属于间接赋值。

上面的代码中我们写入了静态代码块，实例代码块，从返回结果大家也很明显能看出，我们是先调用了静态代码块，在调用实例代码块，最后才运行构造函数

在前面我们提到过静态代码块是在类初始化的时候调用的，所以当我们Class c = Class.forName("org.example.FunctionSort$Test")的时候就自动运行了静态代码块的逻辑。而实例代码块是构造器在调用的时候才运行的，它会被插到每个构造方法内，具体位置在super()之后，构造器自己代码之前。

所以反射+静态代码块是我们一个非常好用的武器。
